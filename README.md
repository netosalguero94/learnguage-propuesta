# Learnguage · Propuesta de página

Propuesta visual con cursos, precios, rutas de aprendizaje, certificaciones y viajes académicos.

Sitio estático: abrir index.html o publicar la rama main desde la raíz con GitHub Pages.

La galería permite consultar y descargar las piezas promocionales. Los importes y condiciones deben confirmarse con el centro antes de contratar. El formulario prepara un correo en la aplicación del visitante.
